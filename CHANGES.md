## 📋 À Faire Avant de Lancer

1. **Configurer EmailJS** (5 minutes)
   - Suivez [`assets/docs/EMAILJS_SETUP.md`](assets/docs/EMAILJS_SETUP.md)
   - Remplacez les 3 IDs dans `assets/js/main.js`

2. **Ajouter vos images** (2 minutes)
   - Place `moussa.webp` dans `assets/images/`
   - Place `about.jpg` dans `assets/images/`

3. **Mettre à jour les données** (5 minutes)
   - Compétences et projets dans `main.js`
   - Infos personnelles dans `index.html`
